Inline, CDN-free icon (Lucide-derived geometry). Inherits color via `currentColor` and scales with `size`. Use it anywhere a component takes an icon node.

```jsx
<Icon name="search" />
<Icon name="network" size={20} />
<Button tone="primary" iconLeft={<Icon name="plus" size={15} />}>Add element</Button>
```

Curated to the explorer's set (search, network, globe, activity, grid, list, table, database, folder, file-text, external-link, settings, sun/moon, help-circle, chevrons, …). Import `ICON_NAMES` for the full list. For names outside the set, pass your own inline SVG instead.
