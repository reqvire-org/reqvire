### Access Ontology

Access ontology.

#### Metadata
  * type: ontology
  * ontology_base: https://example.test/ontology
  * ontology_prefix: test

#### Ontology
```turtle
@prefix test: <https://example.test/ontology#> .
@prefix owl: <http://www.w3.org/2002/07/owl#> .

<https://example.test/ontology> a owl:Ontology .
test:AccessToken a owl:Class .
test:expiresAt a owl:DatatypeProperty .
```

### Token Response Requirement

The system shall produce token responses with expiry information.

#### Metadata
  * type: requirement

#### Relations
  * specify: [Access Capability](#access-capability)
  * constrainedBy: [Token Response Shape Contract](#token-response-shape-contract)
---

### Token Response Shape Contract

Token response shape.

#### Metadata
  * type: semantic-contract

#### Relations
  * constrain: [Token Response Requirement](#token-response-requirement)
  * use: [Access Ontology](#access-ontology)

#### Shapes
```turtle
@prefix test: <https://example.test/ontology#> .
@prefix sh: <http://www.w3.org/ns/shacl#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

test:AccessTokenShape
  a sh:NodeShape ;
  sh:targetClass test:AccessToken ;
  sh:property [
    sh:path test:expiresAt ;
    sh:minCount 1 ;
    sh:datatype xsd:string ;
  ] .
```
