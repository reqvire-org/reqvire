### Recursive SHACL Requirement

The system shall validate recursive SHACL shape structure against reachable ontology terms.

#### Metadata
  * type: requirement

#### Relations
  * specify: [Recursive SHACL Capability](#recursive-shacl-capability)
  * constrainedBy: [Recursive SHACL Shape Contract](#recursive-shacl-shape-contract)
---

### Recursive SHACL Shape Contract

Recursive SHACL shape contract.

#### Metadata
  * type: semantic-contract

#### Relations
  * constrain: [Recursive SHACL Requirement](#recursive-shacl-requirement)
  * use: [Recursive SHACL Ontology](#recursive-shacl-ontology)

#### Shapes
```turtle
@prefix rec: <https://example.test/recursive#> .
@prefix sh: <http://www.w3.org/ns/shacl#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .

rec:InvoiceEventShape
  a sh:NodeShape ;
  sh:targetSubjectsOf rec:eventSubject ;
  sh:property rec:RecursivePathShape .

rec:RecursivePathShape
  a sh:PropertyShape ;
  sh:path (
    rec:customer
    [ sh:inversePath rec:parentInvoice ]
    [ sh:alternativePath ( rec:primaryLine rec:undeclaredNestedPath ) ]
    [ sh:zeroOrMorePath rec:tag ]
  ) ;
  sh:minCount 1 ;
  sh:maxCount 3 ;
  sh:class rec:InvoiceLine ;
  sh:datatype xsd:string ;
  sh:in ( rec:active rec:archived ) .
```
