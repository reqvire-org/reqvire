### Diagram Generation Test

This test verifies that the HTML export correctly generates and embeds mermaid diagrams for requirements.

#### Details

##### Acceptance Criteria
- `reqvire export --output output` completes successfully.
- Generated HTML pages are produced for the test fixtures.
- Generated HTML for the fixture files matches committed expected outputs.
- Expected outputs include Mermaid diagram blocks with the auto-generated marker comment.
- For the fixture graph, diagram relation labels include `deriveReqT` and `verifiedBy`.
- For the fixture graph, reverse/opposite labels `derivedFrom` and `verify` are not rendered in the diagram relation edges.

##### Test Criteria
- Run export command and assert exit code is 0.
- Assert generated HTML count is at least markdown input count.
- Compare `output/specifications/TestRequirements.html` against `expected/TestRequirements.html`.
- Compare `output/specifications/Subfolder/MixedLinkTypes.html` against `expected/Subfolder/MixedLinkTypes.html`.
- Through exact fixture comparison, assert Mermaid output includes:
  - diagram block generation
  - `%% REQVIRE-AUTOGENERATED-DIAGRAM` marker
  - expected rendered relation labels (including `deriveReqT` in fixture output).
- Explicitly grep generated HTML diagram content to assert:
  - presence of `|deriveReqT|` and `|verifiedBy|`
  - absence of `|derivedFrom|` and `|verify|`.

### File Diagram Attachment Test

This test verifies that element attachments are displayed within file-based diagram node boxes as refinement-identifier links.

#### Test Steps
1. Create a model with elements that have attachments
2. Run export or generate-diagrams command
3. Verify element nodes show attached refinement element names with 📎 prefix
4. Verify attachments appear below element name using `<br/>` separator
5. Verify attachment links are clickable (click handlers present)

#### Expected Results
- Elements with attachments show `Element Name<br/>📎 Refinement Name` format
- Multiple attachments are each on separate lines
- Elements without attachments show only their name
- Click handlers navigate to referenced refinement elements
