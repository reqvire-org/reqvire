# Reqvire Website

This is the static website for Reqvire. It is a Vite + React site built with
`vite-react-ssg`, so production output is plain static HTML, CSS, and assets in
`dist/`.

## Development tools

From the repository root, `source bin/activate-hermit` and `hermit install`
provide pinned Bun and Node versions along with the other Reqvire development
tools. Using your own compatible tools is also supported. `package-lock.json`
remains the dependency receipt. Bun may create an untracked `bun.lock` while
importing it; keep that generated file out of commits.

## Commands

```sh
bun install --no-save
bun run dev
bun run build
bun run preview
```

The Makefile wraps the same commands:

```sh
make dev
make build
make preview
make clean
```

## Structure

- `src/App.tsx` declares the static routes used by `vite-react-ssg`.
- `src/pages/` contains page-level content.
- `src/components/` contains the shared layout, sidebar, footer, logo, and UI primitives.
- `public/` contains fonts, images, and static assets copied into the build.
- `dist/` is generated by `npm run build` and should not be edited directly.

## Deployment

For GitHub Pages, build this package from `website/` and publish
`website/dist` with a GitHub Actions Pages deployment. Configure Pages to use
GitHub Actions as the source, not branch or `/docs` publishing.

The build also emits `404.html` from `index.html` so direct links and refreshes
work on GitHub Pages for client-side navigation.
