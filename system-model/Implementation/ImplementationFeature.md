# Elements

### Implementation Traceability

As a **System Engineer**, I want Reqvire to trace implementation evidence through requirement obligations and capability hierarchies, so that I can identify implemented obligations and explain remaining implementation gaps.

#### Details
Implementation traceability owns implementation evidence assessment and implementation coverage semantics for requirements and capability roll-up. Reporting consumers reuse the evaluation contracts owned by its requirements through Contract Bindings.
